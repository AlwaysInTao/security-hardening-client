# Security Hardening Client

An automated security auditing and hardening client designed to assess system vulnerabilities and apply protective baselines across systems. Built with Python and a high-performance Flet GUI.

## 🚀 Installation & Setup

This client is structured as a standalone Python package. You can install it natively into your local environment with a single command:

1. Clone this repository and navigate to the project directory:
   ```bash
   cd security-hardening-client
   ```

2. Install the package using `pip`:
   ```bash
   pip install .
   ```

3. Launch the application from anywhere in your terminal:
   ```bash
   security-hardening-client
   ```
